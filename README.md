# YammyLaunch

Лаунчер Minecraft, который я собрал под себя, потому что надоело возиться с официальным. Написан на Rust (Tauri 2) и React, весит около 11 МБ и не тянет за собой Chromium.

Работает на Windows 10/11 x64.

Telegram разработчика: [@YammyLaunch](https://t.me/YammyLaunch) — новости, обновления, поддержка.

## Что умеет

Запускает Minecraft любой версии, от 1.0 до самых свежих (включая новые год-версии 26.x). Java скачивает сам, нужную под версию игры, ставить ничего не надо.

Лоадеры: Vanilla, Fabric, Forge и NeoForge. Лаунчер сам показывает, какие из них подходят под выбранную версию, так что NeoForge на 1.16.5 он вам не предложит.

OptiFine ставится в один клик, для Fabric автоматически подтягивается OptiFabric. Но OptiFine отстаёт от новых версий, поэтому для них есть пак оптимизации: Sodium, Lithium, FerriteCore, Iris и компания. На NeoForge эти моды тоже есть, и работают они там лучше всего.

Моды ищутся прямо в лаунчере через каталог Modrinth, зависимости ставятся сами. Есть и готовые сборки (модпаки): нашёл, нажал установить, играешь.

Аккаунты: вход через Microsoft (лицензия, официальные сервера) и оффлайн-ник для одиночки и пиратских серверов. Токены Microsoft лежат в Credential Manager Windows, а не в текстовом файле.

Ямми, встроенный ИИ-помощник. Отвечает на вопросы по майну, разбирает краши по логам, советует моды. Работает сразу после установки, ничего настраивать не нужно. Если есть свой ключ ИИ-сервиса, его можно вписать в настройках.

Лаунчер смотрит на железо (процессор, память, видеокарту) и по кнопке подбирает объём памяти и JVM-флаги под конкретный комп.

Каждая сборка живёт в своей папке: свои миры, моды, конфиги. Ничего не конфликтует.

## Установка

Скачать последнюю версию:

- [YammyLaunch_0.2.0_x64-setup.exe](https://github.com/jamersus292-sys/YammyLaunch/releases/download/v0.2.0/YammyLaunch_0.2.0_x64-setup.exe) — установщик (6,4 МБ)
- [YammyLaunch-0.2.0-portable.exe](https://github.com/jamersus292-sys/YammyLaunch/releases/download/v0.2.0/YammyLaunch-0.2.0-portable.exe) — portable, работает без установки (11,3 МБ)

Все релизы: [страница Releases](https://github.com/jamersus292-sys/YammyLaunch/releases).

Запустите установщик. Windows покажет предупреждение SmartScreen, потому что приложение без цифровой подписи: нажмите «Подробнее», потом «Выполнить в любом случае».

Java и файлы игры скачиваются при первом запуске сборки. Все данные лежат в `D:\YammyLaunch` (если диск D есть) или в `%APPDATA%\YammyLaunch`.

## Сборка из исходников

Понадобятся Node.js 20+, Rust (stable-msvc) и Visual Studio Build Tools с workload «Desktop development with C++». WebView2 обычно уже есть в Windows 10/11.

```
npm install
npm run tauri dev
```

Релизная сборка:

```
npm run tauri build
```

Установщик появится в `src-tauri/target/release/bundle/nsis/`.
